기숙사 미로 에셋 64x64

- floor/floor_main.png: 유일한 기본 바닥. 미로에서 길인 칸마다 동일하게 사용.
- wall/: 모두 이동 불가. 기본 벽을 많이 쓰고 특수벽은 드물게 배치.
- door/: 문이 있는 벽(기본 이동 불가). 특정 이벤트 시에만 출입하도록 별도 구현.
- decor/: 장식; 바닥과 분리한 이미지가 아닌 원본 일러스트의 바닥 포함 장식 타일. 기본 바닥을 대체해서 사용하거나 별도 오브젝트 충돌 처리.
- 모든 파일은 정확히 64x64 RGBA PNG.
- 미로 구조와 충돌은 게임의 배열 값으로 판단하고 이미지 색상으로 판단하지 말 것.
